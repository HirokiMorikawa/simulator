物理パラメータ

重力の向きが影響するのは自由体への直接の重力積分のみ——浮力・大気抗力の向きは水域モデルが水平面固定なため変わらない(既知の制約)。

dt の変更はリプレイの再現性に影響するため Edit モードのみ。

環境(大気・水域)

大気・水域は`BuoyancyDrag`結合(Inspectorの Add Coupling)を持つ剛体にのみ効く。設定はEditモード・Playモードどちらでも即座に反映される。

ドメイン(熱ノード・格子流体・気体)

Add Couplingの残り6種(PhaseChangeMorph/SphRigid/GridFluidRigid/BoussinesqBuoyancy/ConvectionLink/PistonGas)は、参照するドメインが有効なシーンでのみ追加できる。ここで先にドメインを作る(冪等——複数回押しても壊れない)。

量子ドメイン(プリセット)

シーンJSONのraw_stateは任意の波動関数・ポテンシャルを保存できるが、構築レシピ(ガウス波束・矩形障壁・調和振動子)はスキーマから撤去済み——ここはエディタ限定のプリセット計算で、ガウス波束を生成しシーンJSONと同じ生配列としてWorldへ渡す。原子単位(ℏ=mₑ=1)。
